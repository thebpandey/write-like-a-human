# Banned Vocabulary

Merged from lguz's tiered dictionary, brandonwise's 3-tier vocabulary,
Aboudjem's P7 triggers, blader's Wikipedia-derived word lists, and The
Humanizer's buzzword bans. Words below appear at statistically abnormal rates
in LLM output. Tier 1: replace on sight. Tier 2: max once each, only where
natural. Tier 3: fine alone, a tell when clustered.

## Tier 3: Transitions (fine alone, a tell when clustered)

| AI transition | Human alternative |
|---------------|-------------------|
| Furthermore | Also, And, Plus |
| Moreover | On top of that, And |
| Additionally | Also, And |
| Consequently | So |
| Nevertheless / Nonetheless | Still, But, Even so |
| Subsequently | Then, later |
| Hence / Thus | So |
| Indeed | (usually delete) |
| In conclusion / In summary | (just conclude; don't announce it) |

Rule: more than 2 formal transitions in a short section is a tell. Often the
best transition is none.

## Banned phrases

- "In today's [fast-paced / digital / ever-evolving] [world / age / landscape]"
- "It's worth noting that" / "It's important to note that" -> just state it
- "plays a crucial role in" -> say what it does
- "serves as a testament to" -> say what happened
- "harness the power of" / "embark on a journey" -> cut
- "without further ado" / "let's dive in" / "let's explore" -> cut, start
- "here's a breakdown" / "Below is..." -> cut, give the list
- "at the end of the day" / "when it comes to" -> cut
- "a step in the right direction" / "the future looks bright" / "exciting times lie ahead" / "poised for growth" -> end with a specific instead
- "not only ... but also" -> two plain clauses or one direct claim
- "key takeaways" -> just give them
- "circle back" / "move the needle" / "low-hanging fruit" / "pain points" / "double-click on" / "value-add" / "net-net" / "bandwidth" (figurative) -> plain speech
- "The truth is," / "And honestly?" / "Let's be honest" as candor-openers -> just state the claim
- "Read that again." / "Let that sink in." -> cut both; earn the pause or lose it
